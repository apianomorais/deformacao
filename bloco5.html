1. Etapa 1: montagem

Sua vez (no computador)

Notebook 3. Em quatro etapas, você vai escrever o seu próprio código de elementos finitos e validá-lo contra a solução analítica do bloco 2.

A primeira etapa é escrever as duas matrizes do elemento e somá-las nas posições certas da matriz global. O único ponto onde se erra é a lista de graus de liberdade: o elemento \(e\) ocupa as posições \(2e\), \(2e+1\), \(2e+2\) e \(2e+3\), e os dois do meio são compartilhados com o elemento vizinho.

import numpy as np

def matrizes_elemento(EI, rhoA, l):
    """Matrizes de rigidez e de massa de um elemento de viga de Hermite."""
    K = EI/l**3 * np.array([
        [ 12,    6*l,   -12,    6*l  ],
        [ 6*l,   4*l*l, -6*l,   2*l*l],
        [-12,   -6*l,    12,   -6*l  ],
        [ 6*l,   2*l*l, -6*l,   4*l*l]])
    M = rhoA*l/420 * np.array([
        [156,   22*l,   54,   -13*l  ],
        [22*l,   4*l*l, 13*l,  -3*l*l],
        [54,    13*l,  156,   -22*l  ],
        [-13*l, -3*l*l,-22*l,   4*l*l]])
    return K, M


def monta(ne, L, EI, rhoA):
    """Monta K e M globais de uma viga dividida em ne elementos iguais."""
    l = L / ne
    n = 2 * (ne + 1)                      # 2 graus de liberdade por no
    K = np.zeros((n, n))
    M = np.zeros((n, n))
    for e in range(ne):
        Ke, Me = matrizes_elemento(EI, rhoA, l)
        gdl = [2*e, 2*e + 1, 2*e + 2, 2*e + 3]
        K[np.ix_(gdl, gdl)] += Ke
        M[np.ix_(gdl, gdl)] += Me
    return K, M

2. Etapa 2: contorno e solução

O engaste é a parte mais simples do código e a mais fácil de esquecer: sem ele, o problema tem dois autovalores nulos, correspondentes a transladar e girar a viga inteira como corpo rígido, e as frequências saem todas erradas.

import numpy as np
from scipy.linalg import eigh

# lamela de aco: 40 mm livres, 1 mm de espessura, 10 mm de largura
L, h, b = 0.040, 0.001, 0.010
E, rho = 200e9, 7850
I, A = b*h**3/12, b*h
EI, rhoA = E*I, rho*A

ne = 10
K, M = monta(ne, L, EI, rhoA)

# engaste em x = 0: elimina w_1 e theta_1, que sao os dois primeiros graus
Kc, Mc = K[2:, 2:], M[2:, 2:]

lam, vec = eigh(Kc, Mc)               # resolve K phi = lambda M phi
f = np.sqrt(lam) / (2*np.pi)          # frequencias em Hz
print(np.round(f[:3], 2))             # [ 509.61 3193.8  8944.7 ]

A função eigh do SciPy resolve o problema generalizado diretamente, sem que seja preciso inverter \(\Ten{M}\). Ela exige que as duas matrizes sejam simétricas e que \(\Ten{M}\) seja definida positiva, o que é o caso depois de imposto o engaste.

3. Etapa 3: verificação

Validar é comparar com o que já se sabe. Compare \(f_1\), \(f_2\) e \(f_3\) com a fórmula do bloco 2 e plote os modos numéricos por cima dos analíticos.

import numpy as np

BL = np.array([1.8751041, 4.6940911, 7.8547574])
exato = BL**2 / (2*np.pi*L**2) * np.sqrt(EI/rhoA)

for ne in (2, 10, 50):
    K, M = monta(ne, L, EI, rhoA)
    lam, _ = eigh(K[2:, 2:], M[2:, 2:])
    f = np.sqrt(lam[:3]) / (2*np.pi)
    erro = 100 * (f - exato) / exato
    print(f"ne={ne:3d}  f={np.round(f,1)}  erro={np.round(erro,3)} %")

4. Etapa 4: convergência

Com apenas dois elementos, \(f_1\) já sai com erro de 0,05 %, e \(f_3\) erra 22 %. Por quê? Porque cada elemento só consegue representar uma cúbica, e o terceiro modo tem muito mais curvatura que o primeiro: não cabe em duas cúbicas emendadas.

Note que as frequências do MEF são sempre maiores que as exatas. Isso não é coincidência: restringir a solução a um conjunto de funções é o mesmo que acrescentar rigidez ao sistema, e um sistema mais rígido vibra mais depressa. Essa propriedade, que vale sempre, é uma das maneiras de saber se o código está certo.

A ideia em uma frase

Quanto mais alto o modo, mais malha ele exige. É a mesma razão pela qual, numa peça furada, a malha precisa ser refinada em volta dos furos: ali a solução tem mais curvatura.

Se sobrar tempo
  1. Coloque uma massa concentrada na ponta, somando \(m\) na posição do deslocamento do último nó de \(\Ten{M}\), e veja a frequência cair;
  2. Use a condição livre-livre, sem eliminar linha nenhuma, e confirme que aparecem dois autovalores nulos e que as razões dos demais são 1 : 2,76 : 5,40;
  3. Varie a seção ao longo do comprimento, dando um \(I\) diferente a cada elemento, algo que a fórmula analítica não consegue fazer. É assim que se projeta o rebaixo de uma lâmina de marimba.
import numpy as np
import matplotlib.pyplot as plt

nes = np.arange(1, 25)
erros = []
for ne in nes:
    K, M = monta(ne, L, EI, rhoA)
    lam, _ = eigh(K[2:, 2:], M[2:, 2:])
    f = np.sqrt(lam) / (2*np.pi)
    erros.append([abs(f[i] - exato[i])/exato[i] if i < len(f) else np.nan
                  for i in range(3)])
erros = np.array(erros)

plt.figure(figsize=(8, 5))
for i in range(3):
    plt.loglog(nes, erros[:, i], "o-", label=f"modo {i+1}")
plt.axhline(0.01, color="0.7", ls="--")
plt.text(1.1, 0.012, "1 %", color="0.4")
plt.xlabel("numero de elementos"); plt.ylabel("erro relativo")
plt.legend(); plt.grid(True, which="both", alpha=0.3)
plt.tight_layout(); plt.show()
